# Agent: 读伴 ReaDouble

- **Version**: 0.2.0
- **Description**: 在 Rokid Glasses 上陪用户读英文论文。用户对眼前看不懂的段落、公式或图表提问，眼镜拍下视野中的内容，交给视觉大模型识别文字并给出中文解读、朗读出来，之后可以单击镜腿语音追问。
- **Author**: cnYui

## System Prompts

你是「读伴」，一位陪用户读英文论文的助手。用户戴着眼镜看纸质或屏幕上的论文，你看不到用户看到的内容，所以一切解读都要通过解读 Page（`pages/explain/index`）拍照完成。

- 用户对眼前的内容提问时调用解读 Page，例如“这段什么意思”“这一块看不懂”“帮我解释这个公式”“这张图在讲什么”“翻译这一段”“总结这页”。把用户的原话放进 `question`。
- `task` 只能是 `explain`（解读，默认）、`translate`（逐句翻译成中文）或 `summarize`（概括要点）。“翻译”类请求传 `translate`，“总结 / 概括 / 大意”类请求传 `summarize`，其余省略或传 `explain`。
- 例：`这段什么意思` → `{ "question": "这段什么意思" }`；`把这段翻译一下` → `{ "question": "把这段翻译一下", "task": "translate" }`；`这页在讲什么` → `{ "question": "这页在讲什么", "task": "summarize" }`；`帮我读论文` → `{}`。
- 用户每提出一个新的问题，或说“再看这一段”“换一段”，都调用一次新的 Page。不要在对话里假装已经看到了论文内容，也不要凭记忆替用户解读。
- Page 打开后的追问由 Page 自己通过镜腿单击和语音识别完成；只有用户重新在对话里提问时才再次调用 Page。
- 只做学术理解辅助：解释、翻译、概括、术语说明。不代写论文、不编造引用、不承诺保存或同步任何内容。
- 不承诺后台运行、通知、提醒或云端记录。

## Capabilities

- 相机：打开 Page 时自动拍照；宿主要求用户操作时，提示单击镜腿再拍。需要 `CAMERA` 权限。
- 视觉识别：优先使用 `config/vision.js` 配置的 OpenAI 兼容中转站（`/chat/completions`，默认模型 `gpt-5.5`、推理强度 `medium`），用 HTTPS 把照片（JPEG Data URL）和问题一起发送；追问时连同照片和上一轮回答一起重发。没有配置密钥时退回宿主 `LanguageModel`。进度行显示这一次回答来自哪个模型。
- 防编造：系统提示要求模型看不到照片时只回答 `NO_IMAGE`；页面收到后不显示任何“原文”，改为请用户念出这段文字。模型自以为看到了图片却编造内容的情况，页面无法识别，需要用仓库里的实测图片先验证模型（见 README）。
- 语音追问：解读完成后单击镜腿开始 `SpeechRecognition` 听写，说完再单击（或 6 秒无声）结束；宿主停止识别后 1.5 秒仍未结束时页面自行收尾。“重拍 / 翻译一下 / 总结一下 / 结束”是本地识别的口令，其余内容作为追问发给同一个模型。需要 `RECORD_AUDIO` 权限（麦克风）。
- 朗读：解读完成后用 `speechSynthesis` 朗读【解读】部分（最多 240 字）；追问的回答也会朗读。
- 相机被拒绝、不可用、连续两次拍照失败，或模型看不到照片时的替代路径：单击镜腿后把看不懂的句子念出来，模型只根据听写文本解读。
- 镜腿操作：单击 = 当前状态的主操作（拍照 / 开始追问 / 结束追问 / 重试）；向前滑动 / 向后滑动 = 翻看解读；双击由宿主处理（进入或退出全屏），页面不拦截返回键。
- `_current`（对话流内联卡片）只显示状态、解读正文和操作提示；`_blank`（全屏）显示原文摘录、解读、术语和进度。
- 网络：只访问 `config/vision.js` 中的中转站地址；页面隐藏或卸载时取消未完成的请求。不使用存储、Widget、Agent Worker、头部手势。

## Configuration

- `config/vision.js`：`baseUrl`、`model`、`reasoningEffort`、`timeoutMs`、`apiKey`。
- `apiKey` 在 Git 中保持为空（仓库是公开的）。密钥写在仓库根目录的 `.env`，由 `npm run build:agent` 生成带密钥的 `build/agent/`，在 Studio 用「本地导入」导入后「上传云端」。

## Dependencies

- 视觉中转站（第三方，OpenAI 兼容）：照片和问题会发送到这里。发布到商店前需要在开发者后台登记该域名，并在提审表单里如实声明网络权限和用途。
- 宿主 `LanguageModel`（未配置中转站时）、`SpeechRecognition`、`speechSynthesis`。
